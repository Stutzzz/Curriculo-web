# Leandro Stutz · Portfólio

Portfólio pessoal de Leandro Stutz da Silva, desenvolvedor front-end e web designer.

Site estático feito com HTML, CSS e JavaScript, com animações em GSAP (ScrollTrigger) e rolagem suave com Lenis.

## Como rodar

```bash
python3 -m http.server 5517
```

Depois abra http://localhost:5517.

## Estrutura

- `index.html`: conteúdo da página
- `css/style.css`: estilos e cores
- `js/main.js`: animações e interações
- `assets/`: imagens, vídeo e currículo (PDF)
